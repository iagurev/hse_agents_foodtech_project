# Дополнение продуктов и проверка рецептов

- Status: Implemented
- Дата: 2026-10-19.
- Основание: поручение проверить справочник, соответствие ингредиентов и рецептуры. Пользователь разрешил справочные КБЖУ с источником, исправление порций под прежними ID и явно помеченное редакторское полное время. Лимит модельного аудита — $1.

Все 4955 ссылок ингредиентов разрешаются в продукты. Ни один SKU не включён в две категории. Исходные 7492 MCP-карточки, 2508 исходных рецептов и прежние документы сохранены без изменения. Статусы исходников остаются 676 ready, 13 preserved_ready, 1819 needs_revision; этот аудит улучшает опубликованные 693 рецепта, а не завершает весь накопленный корпус.

## Продукты и источники чисел

Дополнена 101 ранее неполная категория: 63 получили справочное КБЖУ, ещё 38 — цену на совместимой базе благодаря подтверждённой фасовке. Дополнительно разделены 25 смешанных категорий и перенесены 44 SKU. Различаются, например, пустые и наполненные тарталетки, сухая и приготовленная каша, сырое сырьё и готовые блюда, овощная смесь с рисом и без него. Часть новых категорий остаётся неполной; поэтому прирост активных категорий не равен сумме дополнений и разделений.

КБЖУ простых продуктов дополнены из [USDA SR28](https://www.ars.usda.gov/ARSUserFiles/80400525/Data/SR/SR28/dnload/sr28abbr.zip), с сохранением строк справочника, выбранного соответствия и [описания базы](https://www.ars.usda.gov/ARSUserFiles/80400525/Data/SR/SR28/sr28_doc.pdf). Это справочник 2015 года с документацией, обновлённой в 2016 году; дата аудита не является датой измерения продуктов. База — 100 г съедобной части. Для используемой оценки углеводов из carbohydrate by difference вычтена клетчатка; оба исходных числа и формула сохранены. Калорийность взята из справочника, а не выведена повторно по 4/4/9. Некоторые соответствия обобщённые, например красный лук → сырой лук; это явно справочная оценка категории.

Цены взяты только из товарного снимка ВкусВилла от 17.10.2026. Для фасовок сохранены официальные страницы, прочитанные 19.10; получены 456 страниц, у 364 извлечена явная масса. Placeholder weight не считается доказательством. Граммы и миллилитры не приравниваются. Снимок цены не подтверждает текущее наличие.

Исключены явно противоречивые маркировки, в частности нулевое КБЖУ растворимого кофе и несовместимое энергетическое значение консервированной кукурузы. Поля не переставлялись догадкой. Сырой чеснок, лук и перец получили совместимую числовую базу. Происхождение и прежние значения сохранены в evidence и отчёте.

## Исправления рецептов

Все рецепты прошли проверку состава/шагов и редакторский проход; найденные замечания разбирались по источникам. Не каждое предложение модели принято. Исправлены в том числе сельдерей, ошибочно сопоставленный заправке, и буженина, сопоставленная сырой свинине; уточнено распределение воды, масла, соли и сахара между этапами.

| --- | ---: |
| Состав или сопоставления ингредиентов | 21 |
| Шаги | 145 |
| Оборудование | 279 |
| Название | 18 |

| КБЖУ | 49 |

| Индивидуальное описание ограничений | 693 |

Исправлены шесть бывших порций размером со всю партию: гороховый кисель, сырные шарики, глазированные сырки, яблочное пюре, варенье и сырное мороженое. По решению пользователя сохранены прежние recipe_id. База — явно редакторская доля партии, не измеренная масса готового блюда. Состав и показатели даны на эту порцию, шаги описывают подписанную целую партию. Сохранённые планы автоматически не переписываются: последующий пересчёт такого recipe_id использует исправленную базу.

У 125 рецептов полное время дополнено ожиданием. В карточке есть пометка «Полное время с ожиданием — редакторская оценка», в источниках — прежнее значение, новая оценка и её основание. Прямые числовые времена источника в шагах сохранены. Например, у трюфелей с охлаждением на ночь total теперь 520 минут; это оценка всего процесса, активное время остаётся 25 минут. Универсальная длительность «ночи» не объявляется исходным фактом.

КБЖУ и цены всего каталога пересчитаны кодом из опубликованного состава. Округление — HALF_UP до целых для КБЖУ и до копеек для цен; исходные маркировки и дробные количества не округлялись. Проверяющая команда теперь сверяет арифметику всех рецептов, включая прежние, а также единицы и base_amount доказательств и справочных дополнений.

## Проверки и границы

- Модельный аудит: все исходные 833 продукта и все 693 рецепта; второй предметный проход всех 693; отдельная сверка 143 рецептов с изменёнными шагами. В первом продуктовом проходе использованы все названия связанных SKU и до четырёх полных составов на категорию. Всего 257 оплаченных вызовов, включая повтор неполного ответа; **$0.67851701775** по usage провайдера. Это модельная помощь с проверкой замечаний, не полный ручной аудит каждого товара.
- `uv run python -m app.catalog_check`: SQLite integrity/FK, ссылки, FTS, 7105 наблюдений, 4955 ингредиентов, арифметика и SHA всех 6621 документов проходят. Изменений исходных строк SKU/рецептов/документов нет. Резервные копии и опубликованные SHA сохранены.
- **206 тестов**, Ruff lint/format, Python sdist/wheel, TypeScript и Vite проходят. Новые регрессии проверяют устаревший расчёт прежнего рецепта и неверную базу справочного КБЖУ.
- HTTP-поиск после прогрева: четыре запроса, **15.9–19.8 мс**, status=ok. Это локальный поиск без LLM, не время ответа агента.
- Computer Use: регистрация тестового пользователя, поиск трюфелей и полный рецепт, ингредиенты/шаги, новое время, КБЖУ и фото. Найдена и исправлена гонка FoodImage: эффект сбрасывал loaded после загрузки из кэша, оставляя opacity=0. Результат загрузки теперь связан с src без сбрасывающего эффекта; сборка и повторное открытие проверены.
- Все 693 URL фотографий ответили HTTP 200 с типом image при проверке; это доступность на момент аудита, не гарантия будущего ответа внешнего сервера.

Содержательные ограничения остаются. 133 категории отложены (128 incomplete и 5 needs_revision), неизвестные величины не заполнены догадками. Для четырёх рецептов с варкой и сливом отвара не моделируются потери нутриентов; у облепихового пюре отсутствует измеренный выход после протирания, и в карточке явно указана оценка по ягодам до процеживания. Общие продукты и усреднённые маркировки не подтверждают точный состав любого SKU или отсутствие следовых аллергенов. Использование очищенных SKU-связей и доказанных фасовок при живом подборе корзины остаётся отдельной задачей.

Компактная проекция полного каталога с короткими ID занимает **133181 токен** против 116096 до аудита (`o200k_base`, настройки Luna). Рост связан главным образом с индивидуальными ограничениями. Каталог не усекался; это размер каталога без остальных сообщений генератора. Новые живые меню в рамках аудита не запускались, поэтому улучшение качества самого планирования этой проверкой не доказано.

## Архив и воспроизведение

`../hse_agents_data_archive/catalog-audit-2026-10-19/` хранит original/staged, published-manifest.json, release-report.json, staged-check.json, extra-checks.json, http-smoke.json, исходники USDA/страниц, модельные ответы, ведомости расходов и скрипты подготовки. `sources.sqlite` содержит отчёт `catalog-audit-2026-10-19`, документы с тем же префиксом и прежние payload в реестре подготовки. Разовая подготовка остаётся вне пакета приложения. Рабочая проверка — `uv run python -m app.catalog_check`; структура и пути — в [описании хранения](data-storage.md).
