# Проверка ядра, 2026-10-18

Реализовано и проверено запускаемое локальное ядро. Полная приёмка продуктового MVP не закрыта: живая ссылка корзины недоступна, стартовый корпус мал, качество персонализированного дневного рациона требует более широкой проверки. Корректный JSON сам по себе не считался успешным сценарием.

Текущая детерминированная проверка: **181 тест**, Ruff и сборка пакета проходят. Последние изменения контрактов и числовой проверки описаны ниже. Живые серии относятся к предшествовавшим контрактам.

## Что выявлено и исправлено

- Профиль SDK не знал о native JSON Schema этой модели. Возможность включена явно после протокольной проверки.
- Схемы с `$ref` приводили к сериализации вложенного limits строкой. Использован штатный InlineDefsJsonSchemaTransformer; регрессионный тест проверяет wire schema.
- genai-prices 0.1.13 несовместим с полями RequestUsage SDK 1.68.0 и обнулял счётчики. Совместимая версия закреплена; итоговые суммы серии получены из реальных API usage, включая ранние прогоны.
- Уточнены промпты для временных исключений в памяти, наличия всей требуемой техники, объяснения независимых препятствий, рассчитанных КБЖУ и остановки после partial. Ранние семантические ошибки не скрыты статистикой успешного JSON.
- Декодируются HTML entities в названиях SKU. Неизвестная фасовка остаётся неизвестной, не превращается в выдуманный вес.

## Оставшиеся ограничения приёмки

1. Живой `/cart/link` отвечает HTTP 502, прямой MCP ранее ответил 403. Создание реального URL и аналоги не подтверждены. Частичная корзина честно сохраняется с link_error; кодовая ветка доступной ссылки проверена отдельно.
2. Четыре рецепта не дают репрезентативного меню. В последнем примере без числовой цели модель выбрала день около 1192 ккал и обозначила возможность добавить еду. Это подтверждает расчёт, но **не доказывает соответствие цели «без снижения веса» или пищевую достаточность**. Качество этой части остаётся предварительным; нужны более полный корпус и репрезентативные профили. Новые кодовые критерии или LLM-верификатор не добавлялись.
3. Наблюдаемое соблюдение условий в нескольких повторах не гарантирует отсутствие галлюцинаций. На большом реальном каталоге качество, задержки и устойчивость предпочтений ещё не измерены. Проверка передачи 700 карточек была детерминированной, без LLM.
4. Live streaming провайдера отдельно не прогонялся; проверен SDK streaming. Runtime однопроцессный, экспорт в Langfuse не включён.

Поэтому техническое ядро готово для дальнейшей разработки и локального использования, но считать весь продукт полностью принятым по качеству и внешним интеграциям пока нельзя.

### Найденные ошибки и изменения
