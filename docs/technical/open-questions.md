# Ограничения и следующие решения

- Status: Proposed
- Обновлено: 2026-10-18.
- Утверждённый план закрыл прежние OQ-01—OQ-07: точные limits, память, SQLite, поиск, пороги, промпты и реестр реализованы. Этот документ не отменяет принятые контракты.

| Вопрос | Текущее состояние | Что потребуется дальше |
| --- | --- | --- |
| Рабочий корпус | Стартовый набор из четырёх реальных рецептов; происхождение и расчёты сохранены | Расширить и проверить репрезентативный каталог. Набор для запуска недостаточен для разнообразного недельного меню и многих исключений |
| Качество на большом контексте | Код передаёт 700 контрольных карточек без усечения; качество LLM на таком размере не проверялось | Серия на полном подготовленном корпусе и фактическом системном промпте |
| Товарная интеграция | Прямой публичный MCP: поиск, аналоги и ссылки работают без авторизации; локальный сервер не требуется | Расширять живые сценарии; [подключение](vkusvill.md) |
| Фасовка SKU | Единица продажи кг/л учитывается, штучные фасовки читаются из названия. Поле weight иногда противоречит названию | Использовать подтверждённые доказательства фасовки; неизвестные количества остаются unresolved |
| Оценка цены | Редакторские справочные ставки и прозрачный диапазон, отдельные от стоимости SKU | Пересчитать по проверенным ценовым наблюдениям нужного магазина/региона |
| Production runtime | Мобильный UI, FastAPI, SQLite, серверные сессии, один процесс; после рестарта ход становится interrupted | Публичный deployment, межпроцессный lock и экспорт трасс остаются вне MVP |
| Гарантии семантики | Промпты проверены на небольшой серии; четыре проверки не доказывают выполнение всех пожеланий | Расширять оценку качества. LLM-верификатор и новые проверки плана не добавлены |

Фактические результаты и стоимость: [проверка ядра](verification.md). Планы улучшений не являются скрытыми возможностями текущего приложения.
