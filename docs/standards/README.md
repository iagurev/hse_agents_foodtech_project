# Standards

- [Development rules](rules/): engineering conventions selected through the [agent instructions](../../AGENTS.md).
- [Spec workflow](spec-workflow.md): proportional documentation, clarification, implementation, and closure.
- [Executable specs](executable-specs.md): requirement identifiers, tests, verification evidence, and completion statuses.

These standards describe how to work on the repository. Application scope and architecture belong in approved design, technical, and spec documents. Examples in rules illustrate conventions; they do not imply that the corresponding application components already exist.
