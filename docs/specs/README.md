# Specs

- [_template.md](_template.md): starting point for substantial feature or workflow changes.
- [active/](active/): proposed or approved specifications for current work; drafts do not authorize implementation of undecided behavior.
- [completed/](completed/): implemented, superseded, or retired specs retained for traceability. Only relevant, still-current implemented contracts are authoritative.

Follow [the spec workflow](../standards/spec-workflow.md) to decide whether a spec is needed and how to approve, implement, verify, and close it. Use [executable specs](../standards/executable-specs.md) for requirement IDs, automated tests, other verification, and completion statuses.

Use the template's sections only where they apply. Replace placeholders with real information and links; do not create hypothetical product documents or features just to fill the template.
