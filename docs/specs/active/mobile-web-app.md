# Мобильное приложение

- Status: Implemented
- Основание: утверждённый пользователем план «Мобильное веб-приложение с ассистентом питания», 2026-10-19.

## Требования и приёмка

| ID | Поведение | Проверка |
|---|---|---|
| WEB-01 | Мобильный React/Vite UI без рамки; Чат, Планы, Рецепты, Покупки, настройки из шапки | Computer Use, 360/390/430 px |
| WEB-02 | Логин 1–64; непустой пароль без требований; хеш и HttpOnly сессия 30 дней | API tests |
| WEB-03 | Цель, пол, возраст 14–120, рост 150–230, вес 50–200 обязательны. Бюджет, сложность и ограничения необязательны | API tests, UI |
| WEB-04 | Бюджет: 15–20, 20–25, 25–30, 30–35, 35–40, 40–50 тыс. и без ограничений; один выбор | API tests, UI |
| WEB-05 | Один ход на чат, идемпотентность, SSE reconnect, продолжение без браузера, явная остановка, restart → interrupted | Controlled tests |
| WEB-06 | Guard openai/gpt-oss-safeguard-20b; один вызов, fail closed, заблокированные сообщения только в UI | Controlled + live |
| WEB-07 | Полная UI-история независимо от compaction; только безопасная проекция SDK | Tests |
| WEB-08 | Ручные порции/удаления меню и упаковки/удаления корзины без LLM; версии, конфликт, частичные результаты | Tests + UI |
| WEB-09 | Рецепты актуальных планов без дублей и RAG-поиск по всей базе при вводе запроса; диагностика, детали с фото и составом | UI |
| WEB-10 | Анкета, память с CAS и очисткой; удалить чат без удаления объектов и памяти | Tests + UI |

Таймауты: задача 600 с, модель 180 с, guard 60 с, compaction 180 с отдельно, интеграция 60 с. Число вызовов 12 + 2 compaction. UI не показывает reasoning. Создание ссылки не оформляет заказ. Данные каталогов не пересобираются.

Ручная покупка независима от плана; нерешённые строки сохраняются до явного удаления. «Куплено» переносится только для того же SKU и количества. Старые версии доступны по ID, отдельного UI версий нет. Изменения из чата продолжают существующий harness.

Живая приёмка ограничена $1. Ограничения внешних сервисов и мобильной эмуляции фиксируются отдельно. Код и доступные сценарии проверены. Полная внешняя приёмка ограничена недоступными интеграциями; Implemented не означает подтверждение работы магазина или большого каталога.

Фактическая приёмка: 223 теста, Ruff, TypeScript и обе сборки; Computer Use 360/390/430 px. [Сценарии, расходы и блокеры](../../technical/verification.md#мобильное-приложение--2026-10-19).
