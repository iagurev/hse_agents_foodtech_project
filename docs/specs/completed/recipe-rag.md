# Спецификация интеграции RAG рецептов

- Status: Implemented, включая явные limits, 2026-10-19.
- Основание изменения: пользователь потребовал удалить парсер query, передавать условия через limits, упростить код. Отдельно подтвердил бюджет базовой порции и отсутствие фильтров во вкладке рецептов.
- Источник: [архитектура](../../technical/recipe-rag.md).

| ID | Наблюдаемое поведение | Проверка |
| --- | --- | --- |
| RAG-001 | Лексический и локальный семантический поиск возвращают до 10 существующих карточек | tests/test_retrieval.py |
| RAG-002 | query используется только для поиска; обязательный limits фильтрует до top-k | Исключения продуктов/техники, время, сложность, роли, тип питания, бюджет порции; query не изменяется |
| RAG-003 | Неизвестные исключения не игнорируются; учитываются OR-группы и неопределённость техники. Диета/аллергены не сертифицируются | Неизвестные имена, OR-техника, description tool |

| RAG-006 | Отмена не освобождает занятый CPU worker до завершения | Timeout и cancellation |

search_recipes(query, limits) принимает exclude_products, forbidden_equipment, max_total_minutes, max_difficulty, meal_roles, diet и budget_rub. Бюджет относится к средней оценке одной базовой порции, без прибавки агентом; фильтр допускает превышение до 5%. Null снимает соответствующее ограничение. Неизвестное имя исключённого продукта или техники не игнорируется: допустимые кандидаты отсутствуют. Отдельный аллергенный сертификат не моделируется; соответствие особенностям состава агент оценивает по карточкам.

generate_plan(request, days, limits) и остальные tools не меняются. Генератор сохраняет полный каталог, четыре проверки и одну коррекцию. Вкладка ищет по названиям и ингредиентам с явно пустыми limits; пустая строка показывает рецепты актуальных планов. Общая фильтрация обязательна и при резервном FTS-поиске.

Начальные свидетельства и текущие результаты: [отчёт](../../technical/verification.md). Исторический эксперимент отбора 120 кандидатов не относится к текущей генерации. Подготовка данных не запускается в диалоге; каталог читается напрямую. Первая загрузка локальных весов требует сети. Большой независимый gold set остаётся дальнейшей проверкой качества.
