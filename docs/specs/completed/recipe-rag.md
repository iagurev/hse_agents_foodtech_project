# Поиск рецептов

Октябрь 2026 · Status: Implemented

Основание — согласованное разделение генерации меню и поиска по явным условиям. Реализация: [catalog/search](../../../src/app/catalog/search), устройство — в [архитектуре](../../technical/architecture.md#меню-поиск-и-покупки).

| ID | Поведение | Проверка |
|---|---|---|
| RAG-001 | FTS5/BM25 и локальный ONNX-поиск объединяются через RRF; результат — до 10 существующих карточек | Лексический, dense и гибридный запросы |
| RAG-002 | `query` задаёт предмет поиска, `limits` фильтрует кандидатов до top-k | Фильтры состава, техники, времени, сложности, роли, типа питания и цены |
| RAG-003 | Неизвестное исключение продукта или техники не игнорируется; учитываются OR-группы техники | Пустая допустимая выборка, составные условия |
| RAG-004 | Индекс хранится вне data и связан с хешами каталогов и модели | Повторная загрузка и пересборка |
| RAG-005 | Все поля limits обязательны и допускают null; backend не подставляет профиль, diagnostics остаётся внутренней | Схемы tools и API |
| RAG-006 | Отмена запроса сохраняет занятость CPU worker до его завершения | Timeout и cancellation |
| RAG-007 | Генератор меню получает полный каталог; RAG используется только для поиска | Вход Planner и постоянные ID |
| RAG-008 | Web и CLI используют общий модуль; локальный поиск работает без LLM-ключа | API и CLI |

`search_recipes(query, limits)` принимает `exclude_products`, `forbidden_equipment`, `max_total_minutes`, `max_difficulty`, `meal_roles`, `diet`, `budget_rub`. Бюджет относится к средней цене базовой порции с допуском 5%; `null` снимает соответствующий предел. Смысловую совместимость с пожеланиями агент оценивает по карточкам.

Во вкладке рецептов строка ищет названия и ингредиенты с пустыми limits; без запроса видны рецепты актуальных планов. Резервный FTS применяет те же фильтры. Каталоги читаются без изменения; первая загрузка модели поиска требует сети.

Приёмка: [test_retrieval.py](../../../tests/test_retrieval.py), [контракты](../../../tests/test_contracts_planning.py), CLI и браузерный поиск. Автоматические проверки входят в общий набор 245 passed; протоколы моделей и генерация меню сохраняются.
