# Перенос и обогащение каталога

- Status: completed
- Created: 2026-10-18
- Last updated: 2026-10-18
- Основание: [подготовка каталога](../../technical/catalog-enrichment.md), прямое поручение пользователя.

## Этапы

1. Сохранить проверенные исходные снимки и все MCP-карточки в data; сверить полный набор ID и вложенные поля.
2. Построить воспроизводимую нормализацию продуктов с сохранением уточнений и существующих ID; выделить дубли и неоднозначности.
3. Извлечь доступные факты первоисточников, подготовить количества, порции, КБЖУ, стоимость, время, оборудование и ограничения с журналом происхождения.
4. Проверить контракт и предметные инварианты, создать backup и импортировать подготовленный каталог, сохранив неполные записи для доработки.
5. Выполнить тесты, Ruff, сборку и повторный импорт; записать фактические числа и оставшиеся ограничения.

## Результаты

Выполнение и свидетельства дополняются по ходу работы.

## Промежуточная проверка

- Подтверждено полное семантическое равенство всех 7492 MCP-карточек после переноса; поля наблюдений хранятся отдельно.
- Добавлены тесты парсинга JSON-LD, диапазонов, дробей, сохранения единиц/ID, однозначного сопоставления SKU, запрета переноса КБЖУ/100 г на порцию, идемпотентного полного pipeline и сохранения пользовательских объектов.
- Пользователь подтвердил режим только проверенных данных. Неполные рецепты остаются в собственной базе подготовки с извлечёнными полями, без смягчения обязательного runtime-контракта.

## Итоговая приёмка

Все этапы выполнены в согласованном режиме подтверждённых данных. Рабочая база: 998 продуктов и четыре готовых рецепта. Все 2508 новых рецептов сохранены для доработки, все 7492 MCP-карточки сохранены без изменения полей. Сбор страниц: 2508 успешных, 0 ошибок. Пересборка идентична, повторный импорт не создаёт дублей; backup и неизменность стартовых записей проверены. Полные счётчики и причины доработки — [report.json](../../../../hse_agents_data_archive/2026-10-19/data/preparation/report.json), проверки — [verification.json](../../../../hse_agents_data_archive/2026-10-19/data/preparation/verification.json).

Проверки: `uv run pytest -q` — 101 passed; `uv run ruff check src tests config.py`, `uv run ruff format --check src tests config.py` и `uv build` — успешно. Предметная готовность новых рецептов не объявляется: для неё нужны дополнительные подтверждённые количества, показатели порции и цены.
