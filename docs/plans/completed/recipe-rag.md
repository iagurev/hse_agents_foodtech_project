# Реализация поиска рецептов

Октябрь 2026 · Этапы реализации выполнены

Основание: [спецификация RAG](../../specs/completed/recipe-rag.md).

1. Подключить локальный ONNX encoder и лемматизированный FTS5.
2. Объединить ранжирование через RRF и применить явные limits до выдачи кандидатов.
3. Подготовить производный индекс с проверкой хешей каталогов и ограниченным CPU executor.
4. Подключить общий поиск к tool, HTTP, вкладке рецептов и CLI `meal-rag`.
5. Проверить фильтры, отмену, повторное использование индекса и независимость генератора меню.

Результат: до 10 карточек по запросу, глобальный поиск в UI и полный каталог внутри генератора. Приёмка — [test_retrieval.py](../../../tests/test_retrieval.py), CLI и браузерные сценарии.
