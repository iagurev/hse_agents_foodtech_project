# Реализация RAG рецептов

- Status: completed; согласованная интеграция уточнена 2026-10-19.
- [Архитектура](../../technical/recipe-rag.md), [спецификация](../../specs/completed/recipe-rag.md).

Выполнены локальный ONNX encoder, FTS5/BM25/RRF, явные фильтры limits (парсер query удалён последующим поручением), проверяемый производный индекс, ограниченный executor, интеграция search_recipes/API/UI, CLI и запуск ./run.sh. При объединении генератор сохранён на полном каталоге; search_recipes позднее расширен обязательным limits, автоматический профиль не подключён. Поиск в «Рецептах» глобальный, раздел из планов явно обозначен.

Историческая серия исходной версии включала 183 теста и эксперимент с широким пулом меню. Это свидетельство той реализации, не текущая стратегия генерации. Актуальные проверки объединения и ограничения — в [отчёте](../../technical/verification.md). Независимая оценка релевантности на большом корпусе остаётся открытой.
