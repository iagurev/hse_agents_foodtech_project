# Реализация RAG рецептов

- Status: completed
- Дата: 2026-10-19.
- Авторизация: прямое поручение пользователя полностью реализовать и интегрировать RAG с простым запуском.
- Источники: [архитектура](../../technical/recipe-rag.md), [спецификация](../../specs/completed/recipe-rag.md).

## Выполнено

- [x] Документы и evidence техники, русские леммы и известные продуктовые исключения.
- [x] Локальный закреплённый ONNX encoder, exact cosine, FTS5/BM25 и RRF.
- [x] Производный индекс с SHA исходников/артефактов, автоматическая проверка/пересборка вне data.
- [x] Ограниченный executor, timeout/cancellation и честная лексическая деградация.
- [x] Актуальная анкета/память, мягкие предпочтения, явное снятие временных запретов и diagnostics.
- [x] Native search_recipes, широкий пул Planner, сохранение full_catalog как отката.
- [x] Авторизованный HTTP-поиск, поиск по всей базе в «Рецептах» и переход в полную карточку.
- [x] CLI prepare/search/benchmark и ./run.sh; локальный режим без LLM-ключа.
- [x] Регрессии, фактический индекс/замеры, 30 задач отбора, UI и запуск.
- [x] Продуктовые/технические контракты и Memory обновлены.

## Проверки и ограничения

183 теста, Ruff lint/format, Python sdist/wheel и TypeScript/Vite прошли. Базы каталога не изменились. Первая локальная сборка индекса заняла около 15 с после загрузки весов; тёплая подготовка около секунды. Фактические времена поиска/размеры пулов: [отчёт](../../technical/verification.md#реализация-и-интеграция-rag--2026-10-19).

Большой независимый gold set/сравнение embeddings и живая оценка меню Luna остаются дальнейшими измерениями качества. В этом checkout отсутствует OpenRouter-ключ. Runtime завершён и поддерживает реальный ключ; локальный поиск работает без него. Аллергенная безопасность и полная кулинарная разметка корпуса не объявляются решёнными.
