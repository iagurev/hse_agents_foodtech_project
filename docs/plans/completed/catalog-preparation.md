# Подготовка каталогов

Октябрь 2026 · Этапы подготовки выполнены

Основание: согласованный формат [данных](../../technical/data.md) и продуктовые правила [рецептов и покупок](../../design/product.md#рецепты-и-качество-плана).

| Этап | Результат |
|---|---|
| Сохранение источников | Исходные рецепты, документы и 7492 MCP-карточки сохранены с происхождением и контрольными суммами. |
| Справочник продуктов | Общие названия, алиасы, совместимые единицы, КБЖУ, цены и связи с товарами. Существенные виды сырья разделены. |
| Сопоставление рецептов | Ингредиенты связаны с существующими продуктами; состав, количества, шаги и базовая порция согласованы. |
| Подготовка адаптаций | Авторские варианты имеют собственные идентификаторы и расчёты; исходные материалы сохраняются отдельно. |
| Нормализация показателей | КБЖУ на порцию округлены до целых, цены — до копеек. Фасовки и коэффициенты имеют источник и пометку оценки. |
| Публикация | Три согласованных SQLite-каталога, индексы поиска и проверка воспроизводимости; пользовательские объекты хранятся отдельно. |

Текущий выпуск содержит 693 рецепта, 953 продукта (948 активных) и 4997 связей с товарами. Обновление каталогов выполняется отдельно от диалога, после резервного копирования и проверки.

Приёмка: `uv run python -m app.catalog.check` проверяет SQLite integrity/FK, ссылки, арифметику, FTS, происхождение и исходные документы. Регрессии — в [test_catalog_files.py](../../../tests/test_catalog_files.py). Команда успешно проверила текущий выпуск.
