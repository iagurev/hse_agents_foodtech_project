## Утверждённые уточнения

SQLite; Pydantic AI; шесть русских MD-промптов; 12 доменных tools и update_memory(text).
При создании limits обязательны; редакторы сохраняют условия объекта или меняют по тексту, отдельное отсутствие ограничения — null. Бюджет передаётся без прибавки, код допускает до 5% превышения;
сложность easy/intermediate/advanced; поиск до 10 кандидатов без аргумента размера. Частичная корзина возвращает ссылку
и недостающие продукты с назначением. Память содержит только явно сообщённые устойчивые факты,
полезные для питания и покупок. Генерация: максимум два вызова, ровно четыре проверки.
GLM low для диалога и редакторов, high для генерации меню; 12 запросов и 180 секунд на ход. Сжатие перед каждым запросом при 200k входных токенов,
целый хвост 6→3→1→0; предел входа 232k, отдельные 90 секунд и два вызова. Каталог не усекается. Цель без заданных КБЖУ учитывается качественно.

## Проверка

Проверки схем, четырёх критериев, одной коррекции, версий, изоляции, памяти, call/result,
повторной доставки и контекста. Сценарии GLM и сырые ответы — в /private/tmp.
Прямой MCP ранее ответил 403; поиск через HTTP-адаптер подтверждён, аналоги требуют подключения.
