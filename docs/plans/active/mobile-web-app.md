# Реализация мобильного приложения

Основание: [утверждённая спецификация](../../specs/active/mobile-web-app.md).

1. Перенос Python-пакета в app; конфигурация, упаковка и импорты.
2. HTTP-контракты, сессии и миграции; UI-проекция истории, версии и ручные правки.
3. Guard и фоновые ходы с SSE, отменой и восстановлением состояния.
4. React/Vite: регистрация, чат, планы, рецепты, покупки и настройки.
5. Детерминированные проверки, сборки, живые пробы ≤ $1 и Computer Use.
6. Исправления по проверкам, документация и Memory с фактическими ограничениями.

Все шесть этапов реализованы. Доступная проверка завершена; внешние ограничения и большой каталог отмечены в отчёте. Платные пробы остановлены после отказа ключа, лимит серии не превышен.
