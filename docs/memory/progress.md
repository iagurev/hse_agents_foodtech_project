# Состояние проекта

Октябрь 2026

## Приложение

- Мобильный React/Vite-интерфейс: чат, планы, рецепты, покупки и настройки. Анкета состоит из обязательного и дополнительного шагов.
- Один агент Pydantic AI, 12 предметных инструментов и общая память. Luna medium используется для диалога, меню, правки меню и сжатия; low — для правки покупок и выбора товаров. Guard — Gemini 2.5 Flash-Lite с одной резервной проверкой Luna при временном HTTP-отказе.
- Меню создаётся из полного каталога; RAG обслуживает отдельный поиск. Планы и покупки имеют независимые версии, ручное редактирование, названия и скрытие из коллекций.
- Покупки собираются из меню, рецептов или выбранных товаров через публичный MCP ВкусВилла. Большой список получает несколько магазинных ссылок.
- История нескольких чатов, SSE, остановка, повторная доставка и compaction работают через единый runtime. Langfuse показывает вложенные этапы одного пользовательского хода.

## Данные и проверки

Каталог содержит 693 рецепта и 953 нормализованных продукта, из которых 948 активны. Три SQLite-каталога поставляются через Git LFS; пользовательское состояние хранится отдельно.

Проверка backend 20.10.2026: **289 Python-тест**, Ruff, wheel/sdist. Каталог передаётся без потери данных в компактной таблице; повторяющиеся позиции ответа разворачиваются до расчётов. Исправлены потеря SKU при правке старых корзин, ложные пропуски товаров и гонка доставки конечного SSE-события. Неизвестные поисковые ограничения по-прежнему закрывают выдачу. Временные HTTP- и сетевые отказы MCP допускают один повтор в общем таймауте. Публичные tool-контракты сохранены. Docker и frontend в этой правке не менялись; предыдущая приёмка включала Docker-сборку, пять frontend-проверок, TypeScript, Vite и браузерные сценарии на 360/390/430 px.
