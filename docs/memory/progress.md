### Мобильное приложение, 19 октября

Реализованы React/TypeScript/Vite и FastAPI: четыре вкладки, регистрация/анкета, серверные сессии, чаты и потоковые ответы, input guard, просмотр объектов, ручные правки без LLM, отметки покупки, память и настройки. Python объединён под src/app, настройки в app/config.py. Один процесс, существующая SQLite с добавочными миграциями. Предметные tools сохранены; данные каталогов этим этапом не пересобирались.

Фоновые задачи переживают навигацию/reload; Stop сохраняет журнал/готовые операции. После рестарта статус interrupted без повтора. UI-история независима от compaction.
