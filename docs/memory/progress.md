# Состояние проекта

Октябрь 2026

## Приложение

- Мобильный React/Vite-интерфейс: чат, планы, рецепты, покупки и настройки. Анкета состоит из обязательного и дополнительного шагов.
- Один агент Pydantic AI, 12 предметных инструментов и общая память. Luna medium используется для диалога, меню и сжатия; low — для редакторов и выбора товаров. Guard — Gemini 2.5 Flash-Lite.
- Меню создаётся из полного каталога; RAG обслуживает отдельный поиск. Планы и покупки имеют независимые версии, ручное редактирование, названия и скрытие из коллекций.
- Покупки собираются из меню, рецептов или выбранных товаров через публичный MCP ВкусВилла. Большой список получает несколько магазинных ссылок.
- История нескольких чатов, SSE, остановка, повторная доставка и compaction работают через единый runtime. Langfuse показывает вложенные этапы одного пользовательского хода.

## Данные и проверки

Каталог содержит 693 рецепта и 953 нормализованных продукта, из которых 948 активны. Три SQLite-каталога поставляются через Git LFS; пользовательское состояние хранится отдельно.

Последняя проверка кода: **245 Python-тестов**, Ruff, сборки wheel/sdist и Docker, проверка согласованности каталогов. API и 13 tool-контрактов сохранены при упорядочении модулей. Для frontend выполнены пять проверок расчётов, TypeScript, Vite и браузерные сценарии на 360/390/430 px.

Ориентиры времени отдельных живых запросов: меню на три дня — 54 с, покупка — 45 с, правка порции — 11 с. Это примеры измерений, а не норматив времени ответа.
