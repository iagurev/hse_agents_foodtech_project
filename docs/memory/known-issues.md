# Известные ограничения

Обновлено: 2026-10-20. Исправленные проблемы и исторические замеры — в [проверках](../technical/verification.md) и [пользовательском аудите](../technical/ux-audit.md).

- **Качество состава меню остаётся модельным.** По согласованию добавлен базовый ориентир EER; четыре живых меню дали разумный порядок калорий, явные 2200–2400 соблюдены по дням. Но модель тяготеет к нижней части широкого диапазона без активности, часть дней содержит много жиров, а простая готовка иногда долгая. Малой серии недостаточно для гарантии качества. Новые валидаторы и LLM-верификатор не вводились; четыре проверки остаются ID/числа/сложность/бюджет. [Актуальные результаты](../technical/ux-audit.md#анкета-понятные-поручения-и-дневные-показатели).
- Стоимость плана — расход ингредиентов, корзины — целые упаковки/вес. У проверенного меню 1345,35 ₽, у полной покупки 3652,05 ₽; в тесте бюджет покупки явно увеличен до 4000 ₽. Расчёт бюджета плана оставлен для отдельного обсуждения. Исправления округления и фасовок сами по себе не устраняют эту разницу.
- Подбор SKU модельный: уточнения формы сырья и точные связи исправили проверенные ошибки, но произвольные замены и пропуски ещё возможны. Общий каталог и его классификация не проходили сплошную ручную проверку всех 7492 товаров. Цены каталога из снимка 17.10.2026 не подтверждают наличие.
- Фасовка некоторых SKU неизвестна или ошибочна. Коэффициенты яйца/масла/молока явно оценочные; без подтверждённой фасовки или применимого коэффициента позиция остаётся нерешённой. Кэш не проверяет наличие. Предел MCP 30 разных SKU решён несколькими ссылками; доступность каждой части зависит от интеграции.
- Шаги 633 рецептов очищены от повторных количеств. Остались исходные неоднозначности «часть/остаток» и неудобные точные доли вроде 25/27. Это ещё не полная кулинарная редактура. В четырёх рецептах со сливом отвара не учтены пищевые потери; у облепихового пюре нет измеренного выхода. [Данные](../technical/catalog-audit.md).
- Рабочий каталог: 693 рецепта (676 адаптаций, 13 сохранённых VV-рецептов, четыре другого источника), 953 продукта/948 активных. 1819 исходных рецептов и отложенные категории требуют доработки. Предыдущие фильтры были консервативны; сохранённые предложения не применяются без проверки. [Подготовка](../technical/catalog-cleanup.md).
- Общие категории «Зелень», «Смесь специй», переменный состав SKU и пустые ограничения не гарантируют отсутствие аллергена. В прежнем меню «без кинзы» модель ошибочно подтвердила это. У 114 записей оборудование пустое; исправленная классификация не является независимой проверкой всех рецептов.
- Фильтры явных limits не полностью размечают диетические группы: например, молочная группа не охватывает мацони. Парсера условий query нет. Поиск возвращает кандидатов; семантику проверяет агент. Большой независимый gold set RAG ещё не проверен. Локальный продуктовый FTS с 6271 алиасом не покрывает все словоформы/замены.
- Проекция чата показывает get_recipes как итоговую подборку. Если модель не открывает выбранные ID, остаются поисковые кандидаты. Descriptions уточнены; повтор запроса двух блюд дал две правильные карточки, но это модельное поведение, не извлечение выбора из текста.
- Фото зависят от wsrv.nl и прямого Gastronom; часть показывает заглушку. 360/390/430 px и клавиатурный фокус проверены через CUA. Реальные экранная клавиатура телефона, touch, safe area и screen reader не проверены.
- После удаления памяти в другом чате модель может заявить, что забытый факт сохранён, опираясь на старую переписку, хотя БД/current memory пусты. Обратной записи в выявленном случае нет. Детерминированный механизм забывания не вводился; нужен отдельный разбор контекста.
- Редакторы сохраняют незатронутое по инструкции; корректная схема не гарантирует смысловую точность любой правки. Большие объекты и произвольные диалоги не покрыты живой серией. Прямой SKU без карточки может получить ссылку без подтверждённой цены.
- Luna medium используется для диалога/меню/сводки, low для редакторов/SKU; guard Gemini 2.5 Flash-Lite. Полный каталог сохранён. Задержка провайдера переменна, коррекция может добавить ~15 с. Короткие ID снизили ошибки в небольшой серии, но не гарантируют их отсутствие. Guard прошёл синтетические случаи, а не доказательство защиты от любых атак.
- Счётчик Luna — калиброванная оценка o200k_base, официального шаблона нет; наблюдалось завышение на 1221 и 6044 токена. Запас 8000 не является гарантией для любого контента. Историческая GLM-проба не подтвердила общий вывод с reasoning через max_tokens; при смене endpoint нужна повторная калибровка.
- Compaction однажды спутал отмену замены с отменой увеличенного бюджета. Уточнение исправило проверенный сценарий, но полнота произвольных сводок не доказана. Подробности — в verification.
- Langfuse хранит содержание диалога/анкеты/памяти в закрытом проекте; очистка чата не удаляет traces. Первый диагностический trace имел двойной счёт reasoning в total, первые tools — пустой Input: исправлено для новых записей в окружении local; старые измерения default не переписывались.
- Runtime рассчитан на один процесс. После рестарта незавершённый ход отмечается interrupted без повтора. Последний не записанный фрагмент может потеряться при жёсткой остановке. Langfuse экспортирует в фоне; аварийная остановка может потерять неотправленные spans. Узкое исправление reasoning Pydantic AI опирается на закреплённый SDK; при обновлении сверить с upstream и убрать backport после включения исправления.
- Запуск требует согласованных трёх каталогов; личное состояние/токенизатор находятся рядом с репозиторием. [Пути](../technical/data-storage.md). Время/стоимость отменённого запроса могут не включать usage, которое провайдер не успел вернуть.

[Открытые решения](../technical/open-questions.md) не разрешают добавлять новые нормы или проверки без согласования.
